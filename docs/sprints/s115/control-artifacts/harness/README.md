# Sprint 115 frozen-harness qualification

This directory owns the T-11502 host control. It losslessly preserves stale
Sprint 114 generated state, executes the byte-frozen MH-RS01 self-test without
changing prior-sprint evidence, proves the candidate's external Git boundary,
and returns the four canonical run roots to an absent state before T-11503.
It performs no model inference.

From a normal PowerShell 7 host session at the repository root, run one
command:

```powershell
pwsh -NoLogo -NoProfile -File .\docs\sprints\s115\control-artifacts\harness\qualify-harness.ps1
```

Do not run it inside a restricted process sandbox. The frozen self-test uses
WSL, Bubblewrap, process limits, and network-namespace canaries. It can take
roughly 10–20 minutes on this machine, plus several minutes to hash a large
stale tree. The retained quarantine can require roughly twice the space of one
generated harness run. Close memory-intensive applications first; the command
does not stop unrelated processes.

## Boundary and evidence

The control has only four canonical mutable run roots:

- `target/s114-experiment/app-harness`
- `target/s114-experiment/self-test-workspaces`
- `target/s114-experiment/app-workspace`
- `target/s114-experiment/launcher-attestation-probe`

For every present root, a custom non-following walker records each relative
path, type, size, regular-file SHA-256, and reparse target. The source root must
be a real directory, but a descendant symlink is retained as a reparse record
and is never followed. The script rechecks both endpoints immediately before a
same-volume `Move-Item`, then requires the before/after JSONL manifests to be
byte-identical. It never recursively deletes or cleans a tree.

Raw bytes remain under an atomically claimed numeric attempt such as
`target/s115-preserved-preflight/attempt-001/`. Its numeric batches are:

1. `001-pre-selftest` — stale roots present before the gate;
2. `002-frozen-copy` — the retained depth-preserving frozen harness copy;
3. `003-post-selftest` — every canonical root regenerated by the self-test and
   standalone-Git probe.

The attempt directory is created with a fail-on-collision operation. A failed
or interrupted run remains immutable diagnostic evidence; rerunning the same
one command claims the next unused number. Existing attempts are not
overwritten, removed, or reused.

Before allocating that number, the command takes an exclusive host file lock
at `target/s115-preserved-preflight/qualification.lock` and holds it through
publication or terminal-failure capture. A concurrent qualifier therefore
fails before touching any canonical root. The retained lock file is never
deleted.

On success, compact evidence is moved to the matching tracked path under
`attempts/001` (or the later number). The ignored raw quarantine—including the
large build products—stays under `target/` and must not be committed. Compact
evidence includes command streams, exact argv and timeouts, frozen-copy
manifests, self-test summary and journal snapshot, every move manifest, the
standalone Git proof, a full live-journal output audit, `result.json`, and an
exact `files.sha256` inventory.
The exact qualifier, verifier, parser/static test, and README bytes are copied
into the attempt and bound by size and SHA-256 so later verification does not
silently substitute a newer control implementation.

If pre-publication verification, the same-volume compact-evidence move, or
post-publication verification fails, the raw attempt receives a hashed
`terminal-failure.json`. No rollback is attempted, and the raw quarantine and
any already-published compact evidence stay in place for diagnosis.

## Why the self-test runs from a copy

Sprint 114's frozen `self-test.sh` writes its summary beneath its own harness
`evidence/` directory. Running that script in place would rewrite immutable
prior-sprint evidence. T-11502 therefore copies exactly the 30 files named by
`frozen-inputs.json`, plus that manifest and its companion, to:

`target/s115-preserved-preflight/attempt-NNN/frozen/app-harness`

That location deliberately preserves the script's six-parent layout:
`scripts` → `app-harness` → `frozen` → `attempt-NNN` →
`s115-preserved-preflight` → `target` → repository. Host and WSL probes both
require `../../../../../..` to resolve to the real repository root. Thus the
unchanged copied script still exercises the real canonical
`target/s114-experiment/*` roots, while its newly generated tracked-style
summary lands only inside the retained Sprint 115 copy. All 30 input hashes,
the five seed hashes, the manifest hash, the copied script hash, and the lack
of extra non-evidence files are re-proved after the run.

The control also proves the original Sprint 114 harness tree, repository HEAD
and tree, full Sprint 114 Git status, and the known unrelated user edit
`docs/sprints/s114/control-artifacts/model/acquisition-tests.json` are
byte-identical before and after.

## What the gates prove

The frozen self-test must reproduce its exact summary schema and counts:
untouched-seed failure, all nine known-good dimensions, 13 static violations,
five dynamic violations, two model-registration cases, deterministic replay,
spoof resistance, infrastructure exit mapping, inherited-limit rejection,
and journal-chain rejection. The copied journal snapshot must equal the live
journal later preserved in `003-post-selftest`.

Every live journal stdout and stderr path is rebased from the old canonical
root to its exact post-quarantine location and rehashed. Every Bubblewrap row
must include `--unshare-user`, `--unshare-pid`, `--unshare-net`, and a JSON
status descriptor. Its launcher record must provide positive child, mount,
network, and PID namespace IDs; the preflight containment stage must also
prove loopback-only interfaces and a failed documentation-address connection.

The standalone Git probe uses the exact sibling roots `app-workspace` for the
candidate and `launcher-attestation-probe` for external metadata. Every Git
command clears inherited repository-discovery variables and names both roots
explicitly. The candidate has no `.git`, explicit status is clean, and an
ambient discovery attempt with `GIT_CEILING_DIRECTORIES` fails. No
`--separate-git-dir`, checkout, reset, clean, or candidate repair is used.

## Verification

The qualifier runs the standalone verifier before and after publishing compact
evidence. To verify retained attempt 001 again without rerunning the harness:

```powershell
pwsh -NoLogo -NoProfile -File .\docs\sprints\s115\control-artifacts\harness\verify-harness.ps1 -EvidenceRoot .\docs\sprints\s115\control-artifacts\harness\attempts\001 -CheckQuarantine
```

`-CheckQuarantine` rewalks and rehashes the ignored raw trees, including
descendant reparse records, every journal output, and every Bubblewrap launcher
attestation. Omit it only for a compact-evidence-only offline check after the
raw quarantine is unavailable.
Compact-only verification checks the historical absence attestation but does
not require those live paths to remain absent forever; the live handoff check
is enforced only with `-CheckQuarantine`.

The parser/static control test performs no moves, creates no attempt, and does
not launch WSL:

```powershell
pwsh -NoLogo -NoProfile -File .\docs\sprints\s115\control-artifacts\harness\test-harness-control.ps1
```

It verifies that both scripts parse and that the immutable-attempt,
non-following manifest, same-volume move, `finally` preservation, timeout,
Git-isolation, network-disabled, and no-recursive-deletion surfaces remain
present.
